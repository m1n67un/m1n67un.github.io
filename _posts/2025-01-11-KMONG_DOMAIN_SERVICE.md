#### 1. 서비스 개요

도메인 연동 작업 서비스는 고객이 소유한 도메인을 원하는 플랫폼, 웹사이트 또는 애플리케이션에 연동하는 과정을 지원합니다. 이 메뉴얼은 도메인 연동 작업의 전반적인 절차와 고객이 준비해야 할 항목을 안내합니다.

---

#### 2. 주요 서비스 항목

- 도메인 구매 또는 기존 도메인 활용 여부 확인
- 네임서버 설정 변경 지원
- DNS 레코드 설정 (A, CNAME, MX, TXT 등)
- HTTPS 보안 인증서 (SSL) 적용
- 도메인 정상 작동 확인 테스트

---

#### 3. 고객 준비 사항

1. **도메인 계정 정보**: 고객이 소유한 도메인 계정의 로그인 정보 (도메인 등록업체 계정 포함).
2. **플랫폼 정보**: 연동할 플랫폼의 기본 정보 (예: 웹 호스팅 서비스, CMS, 애플리케이션 등).
3. **DNS 설정 요구 사항**: 플랫폼에서 요구하는 DNS 레코드 정보.

---

#### 4. 서비스 절차

1. **초기 상담**

   - 요구 사항 파악
   - 도메인 상태 및 연동 대상 확인

2. **계정 정보 확인**

   - 도메인 관리 계정 정보 검증
   - 필요 시 동의 하에 계정 접근 설정

3. **네임서버 설정 변경**

   - 도메인의 네임서버 설정을 플랫폼 요구사항에 맞게 수정

4. **DNS 레코드 구성**

   - **A 레코드**: 서버 IP 주소 연결
   - **CNAME**: 별칭 도메인 설정
   - **MX 레코드**: 이메일 서버 연결
   - **TXT 레코드**: 인증 및 기타 설정 (예: SPF, DKIM, DMARC 등)

5. **HTTPS 적용**

   - 무료 또는 유료 SSL 인증서 설치
   - 인증서 유효성 확인

6. **연동 확인 및 완료**

   - 도메인 정상 작동 여부 테스트
   - 연동 완료 후 고객에게 결과 보고

---

#### 5. 자주 묻는 질문 (FAQ)

**Q: 도메인 등록 업체의 로그인 정보를 제공해야 하나요?**
A: 네, 도메인 설정 변경을 위해 반드시 필요합니다. 안전하게 정보를 관리하며 작업 완료 후 계정 비밀번호 변경을 권장합니다.

**Q: HTTPS 적용이 필수인가요?**
A: 최근 보안 트렌드에 따라 HTTPS 적용은 필수입니다. 고객의 웹사이트 신뢰성을 높이는 데도 도움이 됩니다.

**Q: 작업 완료 후 추가 비용이 발생할 수 있나요?**
A: 기본 연동 작업 외의 추가 요구 사항이 있을 경우 추가 비용이 발생할 수 있습니다. 모든 비용은 사전에 안내드립니다.
